# MAH-AddressableManager

A module that manages Unity Addressables from loading to releasing in one place. Work with just `LoadAsync` / `Release`; anything you forget to release is reclaimed automatically when its lifetime (Manual / Scene / Owner) ends. Also includes initialization, download, loading by Label, and Editor tools for inspection.
